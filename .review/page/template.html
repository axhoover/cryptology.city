cryptology.city · Review Queue

How this works. Each card is one proposed change to the wiki. Mark it, and add a note when your answer is "with changes". Marks save as you click.

Claude reads your marks at the start of the next monthly review round (or sooner, if you ask Claude to run the review-round skill). It executes approved items exactly as written, with your notes applied; drops rejected ones; amends or reverts applied changes as you mark them; and opens one pull request per round. The page is then republished with the new round. Unmarked items stay.
