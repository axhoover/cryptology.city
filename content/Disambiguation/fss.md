# FSS (disambiguation)

_FSS_ refers to one of the following.

- [[forward-secure-signature|Forward-secure signature]] — a signature scheme whose verification key is fixed across $T$ periods while the signing key is updated each period, so that the signing key of period $i$ does not allow forging for any earlier period.
- [[distributed-point-function#function-secret-sharing-fss|Function secret sharing]] — splits a function $f$ from a class $\calF$ into succinct keys $(k_0, k_1)$, each of which hides $f$, whose evaluations at any input are additive shares of $f$ at that input; DPFs are the case of point functions.
