# ECC (disambiguation)

_ECC_ refers to one of the following.

Elliptic-curve cryptography:

- [[discrete-logarithm|Discrete logarithm]] — DLOG in elliptic-curve groups (ECDLP).
- [[pairings|Bilinear pairings]] — pairings on elliptic curves.
- [[supersingular-isogeny-diffie-hellman|SIDH]] — isogenies between supersingular elliptic curves.

Error-correcting codes:

- [[pseudorandom-error-correcting-code|Pseudorandom error-correcting code]] (PRC) — a keyed code whose codewords are pseudorandom and whose decoding is robust to errors.
- [[oblivious-locally-decodable-code|Oblivious locally decodable code]] (OLDC) — a secret-key locally decodable code whose access pattern hides the decoded position.
- [[learning-parity-with-noise|Learning parity with noise]] (LPN) — decoding a random linear code over $\FF_2$ under Bernoulli noise.
