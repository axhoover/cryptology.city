# CCA security (disambiguation)

_CCA security_ (IND-CCA) refers to one of the following.

- [[public-key-encryption#cca-security|CCA security for PKE]] (IND-CCA2) — CPA plus a decryption oracle before and after the challenge, excluding $c^*$.
- [[public-key-encryption#cca1-security|CCA1 security for PKE]] (IND-CCA1) — the decryption oracle is available only before the challenge.
- [[symmetric-key-encryption#cca-security|CCA security for SKE]] — CPA plus a decryption oracle, excluding ciphertexts output by the encryption oracle.
- [[key-encapsulation-mechanism#ind-cca-security|IND-CCA KEM]] — KEM security with a decapsulation oracle.
