# CPA security (disambiguation)

_CPA security_ (IND-CPA) refers to one of the following.

- [[public-key-encryption#cpa-security|CPA security for PKE]] — a single challenge ciphertext; the adversary encrypts on its own using $\pk$.
- [[symmetric-key-encryption#cpa-security|CPA security for SKE]] — adaptive queries to a left-right encryption oracle.
- [IND\$-CPA security](symmetric-key-encryption#ind-cpa-security) — SKE ciphertexts indistinguishable from uniform strings of the same length.
- [[key-encapsulation-mechanism#ind-cpa-kem|IND-CPA KEM]] — KEM security without a decapsulation oracle.
