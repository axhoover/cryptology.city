# DLOG ⇒ EdDSA

## Statement

With the hash modeled as a [[random-oracle-model|random oracle]], [[digital-signature#eddsa|EdDSA]], including its Ed25519 instantiations, is EUF-CMA secure if [[discrete-logarithm#dlog-in-prime-order-subgroups-of-twisted-edwards-curves|DLOG]] is hard in the prime-order subgroup of the twisted Edwards curve generated by the base point — [[BCJZ21 - The Provable Security of Ed25519 Theory and Practice|BCJZ21]]. BCJZ21 also analyse strong unforgeability and resilience against key substitution for the standardized and deployed Ed25519 variants, which differ in subtle ways — [[BCJZ21 - The Provable Security of Ed25519 Theory and Practice|BCJZ21]].

## Notes

- EdDSA differs from [[digital-signature#schnorr-signatures|Schnorr signatures]] in hashing the public key with the commitment and in deriving the nonce deterministically from the secret key and the message — [[BDLSY11 - High-Speed High-Security Signatures|BDLSY11]].
