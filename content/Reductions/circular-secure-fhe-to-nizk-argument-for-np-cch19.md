# Circular-secure FHE ⇒ NIZK argument for NP

## Statement

If there is a [[homomorphic-encryption#circular-secure-fhe|circular-secure FHE]] scheme, every language in $\classNP$ has an adaptively sound [[non-interactive-zero-knowledge#nizk-arguments-for-np|NIZK argument]] in the common reference string model — [[CCH+19 - Fiat-Shamir from practice to theory|CCH+19]]. Circular security is assumed only at the standard level, negligible advantage for polynomial-time adversaries. The construction applies the [[fiat-shamir-heuristic|Fiat–Shamir transform]] to a trapdoor $\Sigma$-protocol, with a hash family built from the FHE scheme that is correlation intractable for the protocol's bad-challenge function — [[CCH+19 - Fiat-Shamir from practice to theory|CCH+19]].

## Notes

- The same paper obtains NIZK arguments for $\classNP$ in the common reference string model from almost-optimal hardness of search [[learning-with-errors|LWE]] against polynomial-time adversaries in place of circular-secure FHE — [[CCH+19 - Fiat-Shamir from practice to theory|CCH+19]].
- [[learning-with-errors#lwe-with-polynomial-modulus-to-noise-ratio|LWE with polynomial modulus-to-noise ratio]] alone also gives NIZK for $\classNP$ ([[lwe-to-nizk-ps19|LWE ⇒ NIZK]]) — [[PS19 - Noninteractive Zero Knowledge for NP from (Plain) Learning With Errors|PS19]].
