# [NIST17] Post-Quantum Cryptography: Security (Evaluation Criteria)

**Authors:** National Institute of Standards and Technology | **Venue:** NIST Computer Security Resource Center, web page | [Source](<https://csrc.nist.gov/projects/post-quantum-cryptography/post-quantum-cryptography-standardization/evaluation-criteria/security-(evaluation-criteria)>)

# Notes

A web page with no abstract. It reproduces Section 4.A (Security) of NIST's call for proposals for post-quantum cryptography standardization, including the five security strength categories (4.A.5), the MAXDEPTH bound on quantum circuit depth, and NIST's gate-count estimates for key search on AES and collision search on SHA3.
