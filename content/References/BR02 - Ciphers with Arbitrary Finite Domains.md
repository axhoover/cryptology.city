# [BR02] Ciphers with Arbitrary Finite Domains

**Authors:** John Black, Phillip Rogaway | **Venue:** CT-RSA 2002 | [Source](https://doi.org/10.1007/3-540-45760-7_9)

## Abstract

We explore the problem of enciphering members of a finite set $\calM$ where $k = |\calM|$ is arbitrary (in particular, it need not be a power of two). We want to achieve this goal starting from a block cipher (which requires a message space of size $N = 2^n$, for some $n$). We look at a few solutions to this problem, focusing on the case when $\calM = [0, k - 1]$. We see ciphers with arbitrary domains as a worthwhile primitive in its own right, and as a potentially useful one for making higher-level protocols.
