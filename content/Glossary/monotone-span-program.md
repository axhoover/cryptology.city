# Monotone span program

A monotone span program over a field F is a matrix whose rows are labeled by parties together with a fixed target vector; a set of parties is authorized exactly when the target lies in the span of the rows they label - the linear-algebraic characterization of the access structures realizable by linear secret sharing.
